## 1. 语言一览

```stope
// 单行注释
/* 多行
   注释 */

export counter;                 // 导出：声明一个宿主可见的变量（不能再对它 let）
counter = 0;                    // 赋值是语句，不是表达式

let a, b, c;                    // 局部变量，宿主看不到名字
let total;                      // 只声明、不赋初值

while counter < 10 {            // 条件可选，省略即无限循环
    if counter % 2 == 0 {       // if / elif / else
        emit_even(counter);     // 自定义指令调用（需宿主预先注册）
    } elif counter > 8 {
        break;
    } else {
        continue;
    }
    counter = counter + 1;      // 赋值是语句，不是表达式
}

total = args[0] + argc;         // args：按下标取参数；argc：参数个数
return total;                   // 也可返回多个值：return 1, 2;
```

**基本性质**

| 项 | 说明 |
| --- | --- |
| 源码编码 | UTF-16（`std::u16string`）。标识符与关键字限 ASCII，字符串字面量可含任意 UTF-16 码元 |
| 大小写 | 敏感（`if` 不能写成 `IF`） |
| 语句终止 | 语句以 `;` 结束；块以 `{ }` 界定 |
| 空语句 | 单独的 `;` 合法，被直接丢弃 |
| 注释 | `//` 到行尾，`/* */` 可跨行；不支持嵌套 |
| 空白 | 空格、制表 `\t`、垂直制表 `\v`、换页 `\f`、换行 `\n`、回车 `\r` |
| 行号 | 遇 `\n` 递增；块注释与二进制数组字面量内部的换行同样计数 |

## 2. 词法结构

### 2.1 标识符

```
ident = ( letter | "_" ) { letter | digit | "_" } { ":" ( letter | "_" ) { letter | digit | "_" } }
```

- 首字符必须是 ASCII 字母或 `_`，**不能以数字开头**。
- 冒号 `:` 用于命名空间分段，**冒号前后允许空白**，因此 `a : b` 与 `a:b` 是同一个标识符 `a:b`。
- 冒号后必须紧跟标识符首字符，否则报 `unclosed identifier.` 并产出 Invalid Token。
- 无长度限制（实现上不截断，超长标识符只是慢）。

### 2.2 关键字

共 18 个，全部小写。**关键字优先于自定义指令名**——即使注册了同名自定义指令，也仍被识别为关键字。

| 类别 | 关键字 |
| --- | --- |
| 字面量 | `null` `false` `true` |
| 逻辑/算术运算符 | `not`（同 `!`）`and`（同 `&&`）`or`（同 `\|\|`）`idiv`（整除） |
| 控制流 | `if` `elif` `else` `while` `break` `continue` |
| 声明 | `let` `export` |
| 返回 | `return` |
| 参数 | `args`（按下标取参数）`argc`（参数个数） |

### 2.3 整数字面量

```
int  = bin | oct | hex | dec
bin  = "0" ( "b" | "B" ) { "_" | "0" | "1" }+
oct  = "0" ( "o" | "O" ) { "_" | "0"…"7" }+
hex  = "0" ( "x" | "X" ) { "_" | digit | "a"…"f" | "A"…"F" }+
dec  = digit { "_" | digit }
```

- 下划线 `_` 只作视觉分隔，转换前被剔除：`1_000_000` == `1000000`。
- 值域为 **64 位有符号整数**（`long long`）；越界或含有该进制不允许的字符时报 `invalid integer.`。
- 没有 `0b`/`0o`/`0x` 之外的进制；`0` 开头但第二位不是 `b/o/x` 时按 **十进制** 解析：`0009` == `9`。
- 常见反例：`0b2` 会被切成 Invalid（`0b`，报 `invalid integer.`）+ 整数 `2`，不是一条错误后停止。

### 2.4 浮点字面量

```
float = digit { "_" | digit } ( "." { "_" | digit } )? exp?
      | "." digit { "_" | digit } exp?
exp   = ( "e" | "E" ) [ "+" | "-" ] digit+
```

- 值域为 `double`。
- **小数点后可以不写数字**：`1.` 是合法的 `1.0`。
- **指数部分可省略尾数**，因此 `1..2` 会被切成两个浮点 `1.` 与 `.2`（不是范围运算符）。
- 指数缺数字是非法的：`1e` 报 `invalid float.`。
- 单独的 `.` 报 `invalid float.`。

### 2.5 字符串字面量

```
string = '"' { char | escape } '"'
escape = "\" ( "\" | "'" | '"' | "b" | "r" | "t" | "v" | "n" | "f" )
```

| 转义 | 含义 |
| --- | --- |
| `\\` | 反斜杠 |
| `\'` | 单引号 |
| `\"` | 双引号 |
| `\b` `\r` `\t` `\v` `\n` `\f` | 退格 / 回车 / 制表 / 垂直制表 / 换行 / 换页 |

- **只支持上表 9 种转义**。`\0`、`\uXXXX`、`\xNN` 都不支持，遇到会报 `invalid escape character.`
  并**停止处理该字符串余下内容**（字面量的值被截断）。
- 字符串**不能跨行**——未闭合的双引号报 `unclosed string literal.`。
- 没有插值、没有多行字符串、没有原始字符串。

### 2.6 二进制数组字面量

```
binarr = "'" [ base_prefix ] { number } "'"
base_prefix = "b" | "B" | "o" | "O" | "d" | "D" | "x" | "X"
```

| 前缀 | 进制 | 示例 | 结果字节 |
| --- | --- | --- | --- |
| `b` / `B` | 2 | `'b 01000001'` | `0x41` |
| `o` / `O` | 8 | `'o 101'` | `0x41` |
| `d` / `D` | 10 | `'d 65'` | `0x41` |
| `x` / `X` | 16 | `'x 41'` | `0x41` |
| **无前缀** | **16（默认）** | `'41'` | `0x41` |

- 每个数字按给定进制解释成**一个字节**，依次追加；数字内部可用 `_` 分隔，数字之间用空白分隔。
  所以二进制前缀下要写满 8 位：`'b 0100 0001'` 是**两个**字节 `04 01`，不是 `0x41`。
- **超出一个字节的值被静默截断**为低 8 位且不报错：`'d 300'` → `0x2C`。
- 空内容 `''` 合法，得到零长数组。
- 出现该进制不允许的字符（如 `'x zz'`）报 `invalid binary array.`。
- **单引号内没有转义机制**，因此字面量本身不能包含 `'`；未闭合报 `unclosed binary array.`。
- 字面量内部允许换行，且会正常递增行号。

### 2.7 运算符与分隔符

| 符号 | 含义 | 符号 | 含义 |
| --- | --- | --- | --- |
| `,` | 分隔 | `=` | 赋值 / 声明初值 |
| `;` | 语句结束 | `==` `!=` | 相等 / 不等 |
| `(` `)` | 分组、调用、自定义指令参数 | `<` `<=` `>` `>=` | 比较 |
| `[` `]` | 索引、args 取参 | `&&` `and` | 逻辑与 |
| `{` `}` | 块 | `\|\|` `or` | 逻辑或 |
| `+` `-` `*` `/` | 四则 | `!` `not` | 逻辑非 |
| `%` | 取模 | `idiv` | 整除 |
| `^` | 幂 | | |

- `&`、`|` 单独出现是**非法字符**，报 `unknown token.`；只有 `&&`、`||` 合法。
- 没有 `++` `--` `**` `?:` `+=` 等复合形式。
- 没有一元 `+`；一元取负只有 `-`。
- `/` 是除法：两个整数**除不尽时得浮点数**（`7 / 2` → `3.5`，`6 / 2` → `2`）。
  要整除用 `idiv`（`7 idiv 2` → `3`，向零取整）。

## 3. 语法结构（EBNF）

记号：`{ X }` 表示重复零次或多次，`[ X ]` 表示可选，`|` 表示多选一，终结符用引号。

```ebnf
program        = { statement } ;

statement      = empty_stmt
               | let_stmt
               | export_stmt
               | return_stmt
               | block_stmt
               | if_stmt
               | while_stmt
               | break_stmt
               | continue_stmt
               | expr_or_assign_stmt ;

empty_stmt     = ";" ;

let_stmt       = "let" ident [ ( { "," ident } | ( "=" expr ) ) ] ";" ;
export_stmt    = "export" ident { "," ident } ";" ;
return_stmt    = "return" [ expr { "," expr } ] ";" ;
block_stmt     = "{" program "}" ;
if_stmt        = "if" expr "{" program "}"
                 { "elif" expr "{" program "}" }
                 [ "else" "{" program "}" ] ;
while_stmt     = "while" [ expr ] "{" program "}" ;
break_stmt     = "break" ";" ;
continue_stmt  = "continue" ";" ;
expr_or_assign_stmt = expr [ "=" expr ] ";" ;
```

### 3.1 程序

程序就是**平铺的语句序列**：没有包、模块、类型、函数定义语法，也没有入口函数概念。
空输入得到空程序，不报错。

变量分两种：**局部变量**（`let`）只有槽位号，**宿主看不到名字**；**导出变量**（`export`）
会把「名字 → 槽位」登记进 `Program.exports`，宿主可以按名字读写它 —— 宿主常借它放置接口
或预置程序参数。详见 §3.2。

### 3.2 语句

#### `let` —— 变量声明

```stope
let a;              // 声明，无初值
let a = 1;          // 声明并赋初值
let a, b, c;        // 多变量声明
```

- 声明与赋值**互斥**：多标识符形式不能带 `=`。`let a, b = 1;` 报
  `failed to parse let statement with multiple identifiers.`（`=` 与 `1` 各报一次，共 2 条）。
- 单个标识符缺分号时（`let a`）报 `unexpected token in let statement.`；
  多标识符缺分号时报 `expected ";" in let statement.`。
- **已知宽松点**：`let a = 1`（末尾缺 `;`）当前**不报错**——赋值分支吞掉表达式后未校验 `;`。
  这是实现现状，不要依赖。
- **宿主看不到局部变量的名字**：`let` 只分配一个槽位，`Program` 里只有索引，
  名字**不进** `Program.exports`。宿主若需要按名字访问某个变量，必须用 `export` 声明它。

#### `export` —— 导出

```stope
export init;
export init, main;
```

`export` **同时完成声明与导出**：它分配一个变量槽位，并把「名字 → 槽位」写进 `Program.exports`。
因此**不需要、也不能再对同一个名字用 `let`**。

- 宿主按名字从 `Program.exports` 查到槽位后可读写该变量，常见用途有两类：
  **放置接口**（宿主把函数或值填进这个槽位，脚本里像普通变量一样调用，如 `fmt:println`）
  与**当作程序参数**（宿主打入初值，脚本读取）。
- 只接受标识符列表，**不能赋初值**（`export a = 1;` 报 `unexpected token in export statement.`）。
- 语法上可以出现在任何位置，但语义层要求**只能在顶层**（块内使用报
  `"export" can only be used at top scope.`），且同一标识符重复导出会报错。
- 导出的是**变量**，不是函数——本语言没有函数定义语法。
- **与 `let` 对同一名字互斥**（两个方向都报错）：

  | 写法 | 报错 |
  | --- | --- |
  | `export a; let a = 1;` | `duplicate declaration of 'a'. ` |
  | `let a = 1; export a;` | `duplicate export of "a". ` |

- **未声明就使用的标识符也会被导出**。写下一个从未 `let` / `export` 过的名字时，
  编译器把它当作外部变量登记到文件作用域，同样写进 `Program.exports`
  （例：`fmt:println(1);` → `exports = { fmt:println → 0 }`）。
  想让宿主看见某个名字，可以什么都不声明直接用它——但显式 `export` 更安全，
  因为打错字不会得到任何提示。

#### `return` —— 返回

```stope
return;         // 无返回值
return 1;       // 单值
return 1, 2;    // 多值
```

#### 块

```stope
{ let a = 1; a; }
{ }             // 空块合法
```

块自成一层作用域（由语义层定义）。

#### `if` / `elif` / `else`

```stope
if a > 0 { b; } elif a == 0 { c; } else { d; }
```

- `if` 的条件**必须写**；`elif` 同样必须有条件；`else` 没有条件。
- **`{ }` 不可省略**，即使只有一条语句（没有"单语句免花括号"的写法）。
- `elif` 可出现任意次，`else` 至多一次且必须在最后。

#### `while`

```stope
while a < 10 { a; }
while { a; }        // 条件省略 = 无限循环
```

**条件是可选的**，这是 `while` 与 `if` 唯一的结构差别。

#### `break` / `continue`

```stope
break;
continue;
```

必须紧跟 `;`，不带操作数。

#### 表达式语句与赋值

```stope
f(1);               // 表达式语句
a = 1;              // 赋值语句
```

- 赋值是**语句**而非表达式，因此**不能链式赋值**：`a = b = 1;` 会被解析成
  `a = b` 加一条孤立的 `1`，并报 `expected ";" at end of assign statement.`
- 赋值左侧**不做左值检查**：`1 = 2;` 语法上通过，是否报错留给语义分析。

### 3.3 顶层结构小结

| 结构 | 是否存在 | 备注 |
| --- | --- | --- |
| 函数 / 过程定义 | **无此语法** | 程序是平铺的语句序列，没有入口函数 |
| 类型标注 | **无** | `let a = 1;` 不带类型；类型信息由语义层推断 |
| 分隔符 `;` | 必需 | 例外见 §3.2 `let` 的已知宽松点 |

## 4. 表达式与优先级

```ebnf
expr      = prefix_expr { infix_op expr } ;
prefix_expr = unary_op expr
            | primary { postfix } ;
primary   = ident | "null" | "true" | "false" | int | float | string | binarr
            | "(" expr ")" | args_expr | custom_call ;
postfix   = "(" [ expr { "," expr } ] ")"       (* 调用 *)
          | "[" [ expr { "," expr } ] "]" ;     (* 索引 *)
unary_op  = "-" | "!" | "not" ;
args_expr = "args" "[" expr "]" ;
custom_call = custom_name "(" [ expr { "," expr } ] ")" ;
```

### 4.1 优先级与结合性

从**低到高**：

| 级别 | 运算符 | 结合性 | 示例 | 解析结果 |
| --- | --- | --- | --- | --- |
| 1 | `or` `\|\|` | 左 | `a or b or c` | `(a or b) or c` |
| 2 | `and` `&&` | 左 | `a and b and c` | `(a and b) and c` |
| 3 | `==` `!=` | 左 | `1 == 2 != 3` | `(1 == 2) != 3` |
| 4 | `<` `<=` `>` `>=` | 左 | `1 < 2 < 3` | `(1 < 2) < 3` |
| 5 | `+` `-` | 左 | `1 - 2 - 3` | `(1 - 2) - 3` |
| 6 | `*` `/` `idiv` `%` | 左 | `7 idiv 2 % 3` | `(7 idiv 2) % 3` |
| 7 | `^` | **右** | `2 ^ 3 ^ 2` | `2 ^ (3 ^ 2)` |
| 8 | 一元 `-` `!` `not` | 前缀 | `-a * b` | `(-a) * b` |
| 9 | `f(…)` 调用、`a[…]` 索引 | 后缀 | `-f(1)` | `-(f(1))` |

- **`^` 规定为右结合**（2026-10-22 项目定夺；此前为左结合，与多数语言不同，已改回）。
- 一元运算优先级**高于** `^`，所以 `-2 ^ 2` 是 `(-2) ^ 2`，不是 `-(2^2)`。
- 后缀（调用 / 索引）优先级**高于**一元，所以 `-f(1)` 是 `-(f(1))`。
- 括号分组不是运算符，它直接把内部表达式作为一个整体（`(1 + 2) * 3` → `1 + 2` 先算）。

### 4.2 主表达式

| 形式 | 说明 |
| --- | --- |
| 标识符 | 变量引用 |
| `null` `true` `false` | 字面量 |
| 整数 / 浮点 / 字符串 / 二进制数组 | 见 §2.3–§2.6 |
| `( expr )` | 分组，不产生节点 |
| `args[expr]` | 取第 N 个参数，见 §5 |
| `argc` | 参数个数，见 §5 |
| `name(...)` | 自定义指令调用，见 §5 |

### 4.3 调用与索引

```stope
f();            // 零参数合法
f(1, 2);
a[];            // 零下标合法
a[1, 2];
f(1)(2)[3];     // 可链式
a[b[1]];
```

- 参数表 / 下标表的元素都是**完整表达式**，可任意嵌套。
- **空括号 `()` 不是合法表达式**（没有"空元组"），报 `no prefix parse function for token type.`
- 缺 `)` / `]` 时只报错、不吞掉后续 token——被中断的内容会作为下一条语句继续解析。

### 4.4 常量折叠（解析期求值）

语法树是在解析时就建好的，**两侧都是字面量的表达式会当场算成一个字面量**：

```stope
1 + 2 * 3;      // → Int(7)
(1 + 2) * 3;    // → Int(9)
2 ^ 3 ^ 2;      // → Int(512)     （^ 右结合：2^(3^2)）
7 / 2;          // → Float(3.5)   （整数除不尽 → 浮点数）
7 idiv 2;       // → Int(3)       （整除）
2 ^ -1;         // → Float(0.5)   （负指数 → 浮点数）
"ab" + "cd";    // → "abcd"
not true;       // → false
```

三条**本项目自定**的规则（与多数语言不完全一致）：

| 规则 | 例子 | 结果 |
| --- | --- | --- |
| 二进制数组相加 = 字节连接 | `'x 41' + 'x 42'` | 两字节 `41 42` |
| 字符串 / 数组 × 非负整数 = 重复（左右都行） | `"ab" * 3`、`3 * "ab"` | `"ababab"` |
| 算术里 `true` / `false` 当作 `1` / `0` | `true + 1`、`true * 2.5` | `2`、`2.5` |

`==` `!=` `<` `<=` `>` `>=` **不做**上面的布尔折算：`true == 1` 保持原样，由运行期判断。

**不折叠的情况**（保留原表达式，交给运行期）：

- 除数为 `0`：`1 / 0`
- `null` 参与算术：`null + 5`、`null * 5`（null 不是数字，运行期报类型错误）
- `idiv` 含浮点：`1 idiv 2.0`（避免浮点→整数收窄）
- 重复次数为负或非整数：`"ab" * -1`、`"ab" * 2.5`；结果超过 1 M 元素也不折
- `^` 的结果不是有限值：`0 ^ -1`
- **任一侧不是字面量**：`x + 1`、`false and f()`、`myop(1) * 2`
  —— 折叠永远不会吞掉调用、下标、变量读的副作用

整数**溢出不检查**：`9223372036854775807 + 1` 折成 `Int(-9223372036854775808)`，
运行期同样按 64 位补码回绕。`INT64_MIN / -1` 也回绕（不会崩进程），
`INT64_MIN % -1` 是 `Int(0)`。

> 注意：折叠后 AST 不再与源码逐节点对应（上面第一行在树里就是一个 `Int(7)`）。
> 完整的行为矩阵与调整方式见 `cpp/docs/expr-optim.md` §4。

## 5. 内建特性：`args` / `argc` / 自定义指令

### 5.1 `args[expr]`

按下标读取入参。`args` 是关键字，只能以 `args[...]` 的形式出现；写成 `args 0;` 会报
`expected "[" after "args".`，并把 `0;` 留作下一条语句。

### 5.2 `argc`

入参个数，是**叶子表达式**，不需要括号：`a = argc;`。
（写成 `argc()` 语法上也能通过，但会被当成"对 `argc` 的一次零参数调用"，不是本意。）

### 5.3 自定义指令

自定义指令不是语言内置的，而是**由宿主在解析前注册**的：

```cpp
CustomOpcodeConfig cfg;
std::u16string n = u"emit_even";
cfg.addCustomOpcode(n, /*opcode=*/100, /*argNum=*/2);  // argNum < 0 表示变长参数
Parser p(lexer, &cfg);                                 // config 必须在构造时注入
```

- 注册后，标识符在词法阶段就被识别为 Custom Token，因此**输入最开头的自定义指令也能正确识别**。
- 名字遵循标识符规则，可带命名空间：`a:b(1)`。
- 调用文法：`name ( [ expr { "," expr } ] )`，**括号不可省略**（`myop 1;` 报
  `expected "(" after custom opcode.`），参数可以为空（`myop();`）。
- 关键字优先：注册名为 `and`、`if` 等的自定义指令无效，仍按关键字处理。
- 同名重复注册返回 `DuplicateWithBuiltinOpcode`。

## 6. 错误处理与实现限制

### 6.1 错误分两处

词法错误进 `Lexer::errors`，语法错误进 `Parser::errors`，**两者不合并**，调用方需分别检查。
错误文本形如 `line 3: expected ";" or "=". `。同一行的多个错误**全部上报，不做去重**。

### 6.2 错误恢复约定

- 分隔符（`; { [ ) ]`）缺失时，**只报错、不推进 Token**，被中断的内容留给下一轮语句解析。
  例如 `f(1, 2 x; y;` 会解析成三条语句（`f(1,2)`、`x`、`y`）加一条错误。
- 绝不推进 `Eof` 与块内的 `}`（前者会死循环，后者会吞掉外层块的闭合）。
- **顶层孤立 `}` 是错误**：`a; } b;` 报 `unexpected "}" at top level.` 并跳过继续解析；
  块内的 `}` 仍由块自己消费，不报错。
- 解析失败处会返回一个裸 `Expr` 节点（`line == -1`），下游只能靠它或 `errors` 非空来识别。

### 6.3 已知限制

| 限制 | 说明 |
| --- | --- |
| **递归无深度上限** | 解析与析构都是递归的。8 MB 栈下实测：约 12000 层嵌套括号会**解析阶段栈溢出**；约 5000 层嵌套块会在**析构阶段**崩溃。病态输入会直接让进程崩溃，不是报错。 |
| 解析不校验左值 | `1 = 2;` 语法通过 |
| `let a = 1`（缺 `;`）不报错 | 见 §3.2 |
| 空括号 `()` 不支持 | 见 §4.3 |

> 这些限制是**实现现状**，其缺陷编号（PD-x）、源码位置与修法建议见
> [syntax-impl.md §10](syntax-impl.md#10-已知缺陷清单)。

## 7. 与 GDScript 参考实现的差异

参考实现位于 `gdscript/addons/stope/parser.gd`。C++ 侧在以下两处**有意偏离**，其余保持一致：

| 场景 | 参考实现 | C++ 实现 |
| --- | --- | --- |
| 出错后是否推进 Token | `parse_break_stmt` / `parse_args_expr` / `parse_call_expr` / `parse_custom_inst` 等出错后都 `next_token()`（吞掉后续内容） | 只报错、不推进，让后续 Token 作为独立语句重新解析 |
| 顶层孤立 `}` | `prog_end_tokens` 让解析静默结束，后续语句被丢弃 | 报 `unexpected "}" at top level.` 并跳过继续解析 |
